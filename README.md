# metravod/homebrew-tap

Homebrew casks for [metravod](https://github.com/metravod)'s tools, published by GoReleaser.

```sh
brew install metravod/tap/omut
```

| Cask | What it is |
|---|---|
| [omut](https://github.com/metravod/omut) | Meta for a pack of projects that any agent can read and check |
