# metravod/homebrew-tap

Homebrew packages for [metravod](https://github.com/metravod)'s tools.

```sh
brew install metravod/tap/omut
brew install metravod/tap/zori
```

| Package | What it is |
|---|---|
| [omut](https://github.com/metravod/omut) | Meta for a pack of projects that any agent can read and check |
| [zori](https://github.com/metravod/zori) | Run local CLI coding agents in parallel with YAML flows |
